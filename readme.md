# Possibili varianti:

1. Chatbot
crea un'interfaccia chat che risponda in tempo reale alle domande dell'utente su un argomento specifico, gestendo lo storico dei messaggi e mantenendo il contesto della conversazione

2. Analizzatore sentiment
sviluppa una webapp che valuti il tono emotivo di un testo inserito, visualizzando il risultato (positivo/negativo/neutro)

3. Traduttore multilingua
realizza un tool che traduca testi inseriti dall'utente, permettendo di selezionare dinamicamente la lingua di output tramite un menu a tendina

4. Checklist
trasforma un blocco di testo narrativo in una lista di azioni strutturate, ottimizzando l'output per una rapida lettura

5. Validatore di risposte
progetta un sistema che verifichi la pertinenza e la coerenza logica di una risposta data dall'utente rispetto a un contesto o una domanda specifica fornita in input

6. Assistente Email
crea un servizio che riscriva un testo grezzo in formato email professionale, permettendo all'utente di personalizzare tono, uso di emoji e lunghezza del messaggio
